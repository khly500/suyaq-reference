# سِياق AI — Suyaq AI

واجهة عربية متجاوبة لبناء منصة بحث واسترجاع معرفي مخصصة للنصوص العربية. مبنية باستخدام React + TypeScript + Vite.

## ما الذي تتضمنه؟
- تصميم عربي RTL متجاوب مع الهواتف والشاشات الكبيرة.
- صفحة تعريف بالمنصة ومعمارية مقترحة.
- مختبر بحث يعرض المقاطع والدرجات والمصادر.
- حالات تحميل وأخطاء ورسائل توضح وضع العرض التجريبي.
- اتصال اختياري بخادم API عبر `VITE_SUYAQ_API_URL`.

**تنبيه:** النتائج الثابتة في وضع العرض هي أمثلة تصميمية فقط، وليست نتائج RAG فعلية. ملف `worker/worker.js` نقطة بداية API وليس محرك RAG كاملًا.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## النشر على GitHub
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع المجلد الخارجي نفسه كطبقة إضافية).
3. من Cloudflare Pages اختر المستودع.
4. إعدادات البناء:
   - Build command: `npm run build`
   - Build output directory: `dist`
5. انشر الموقع.

## ربط واجهة البحث بخادم API
أنشئ متغير بيئة في إعدادات المشروع:
`VITE_SUYAQ_API_URL=https://your-worker.example.workers.dev/api/query`

يجب أن يعيد API استجابة بهذا الشكل:
```json
{
  "status": "success",
  "retrieval": { "method": "hybrid", "count": 1 },
  "answer": "إجابة مدعومة بالمصادر",
  "matches": [
    {
      "id": "doc-01-chunk-02",
      "score": 0.82,
      "text": "نص المقطع المسترجع",
      "source": "اسم الوثيقة.pdf",
      "page": 12,
      "url": "https://example.com/document.pdf#page=12"
    }
  ]
}
```
إذا كان عنوان Worker نفسه على نفس النطاق، يمكن استخدام `/api/query`.

## ملف Worker
`worker/worker.js` يوضح شكل endpoint فقط. لا يطبق embeddings أو فهرسة أو توليدًا حقيقيًا. لإنتاج RAG فعلي، أضف مسار إدخال الوثائق، استخراج النص، التقطيع، embeddings، مخزن متجهي، استرجاعًا هجينًا، وإجابة مع استشهادات. لا تضع مفاتيح سرية في كود الواجهة أو متغيرات `VITE_*`.

## توصيات قبل إطلاق SaaS
- تسجيل دخول وصلاحيات وعزل بيانات العملاء.
- حدود استخدام ومراقبة أخطاء وتكلفة.
- معالجة آمنة للملفات وسياسة حذف واحتفاظ.
- تقييم عربي لمقاييس الاسترجاع ودقة الاستشهادات.
- عدم اعتبار درجة التشابه نسبة ثقة في صحة الإجابة.
