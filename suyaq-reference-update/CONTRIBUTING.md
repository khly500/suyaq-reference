# المساهمة في سِياق

## تشغيل المشروع
```bash
git clone https://github.com/khly500/suyaq-reference.git
cd suyaq-reference
npm run validate   # فحص data.js
npm run build      # يولّد مجلد dist/ (لا يحتاج npm install)
```

## إضافة برومبت أو كود
1. أضف سطراً في `data.js`:
   - برومبت: `P("id-لاتيني","التصنيف","العنوان","النص مع {{المدخل}}")`
   - كود: `C("التصنيف","Python","العنوان","الكود")`
2. المعرّف `id` حروف لاتينية صغيرة وأرقام وشرطة فقط، لأنه يصير جزءاً من الرابط `/p/<id>/`.
3. شغّل `npm run validate` ثم `npm run build` وتأكد من ظهور الصفحة الجديدة.
4. افتح Pull Request.

## معايير الجودة
- فصحى واضحة، وتعليمات محددة، والكود بالإنجليزية.
- جرّب البرومبت على نموذج فعلي قبل إرساله.
- لا تضف أسراراً أو مفاتيح أو بيانات شخصية.
